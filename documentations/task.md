# Ocean UI Build Tasks

## General Instruction
Before building each page or component, ask for a **clear screenshot** of the exact UI section. Do not proceed without it. This ensures that the final output matches the design.

---

## Full Pages (Must Be Built as Full Views, Not Components)

### 1. Feed Page
- Request a screenshot of the full feed page.
- Build the `FeedPage` with:
  - Top search bar
  - PostCard component(s)
  - Comments section for posts

### 2. Message Page
- Ask for a screenshot of the messaging interface.
- Build the `MessagePage` including:
  - Chat list (left panel)
  - Conversation window (right panel)
  - Search bar and multi-select mode
  - Real-time message view with typing input

### 3. Product Detail Page
- Request screenshot of the product detail view.
- Includes image gallery, seller actions, description, and interactions.

### 4. Auction Page
- Ask for the screenshot of the auction interface.
- Show product details, current bids, bidding form, and countdown timer.

### 5. Distress Sale Page
- Request screenshot showing layout for discounted items.
- Display layout of products with discount badges and filters.

### 6. Saved Items Page
- Ask for screenshot of the saved/favorite products layout.

### 7. Settings Page
- Request screenshot of account settings screen.

### 8. Upload Page
- Ask for a screenshot of the product upload form/page.

---

## Core Components (Reusable)

### Sidebar Navigation
- Request screenshot of sidebar UI.
- Build a reusable `Sidebar` with:
  - Profile section
  - Navigation buttons
  - Logo at bottom

### Chat Sidebar (Right Panel)
- Screenshot needed for chat UI list.
- Build `ChatSidebar`:
  - Search input
  - Chat list
  - Multi-select options

### Post Composer
- Screenshot of comment or post input.
- Reusable `PostComposer` for typing messages/comments.

### Common Reusable UI Elements
Build these after getting screenshots from their first usage:
- `Avatar`
- `PostCard`
- `ChatItem`
- `SearchInput`
- `SidebarItem`
- `PrimaryButton`, `SecondaryButton`
- `ProductCard`

---

**Reminder:** Before building any page or component, always request and confirm a screenshot.
